# Student Marks Prediction Using Supervised Machine Learning

## Project Objective
The objective of this project is to predict student marks based on study hours using supervised machine learning.

## Algorithm
Linear Regression

## Programming Language
Python

## Dataset
The dataset contains two columns:
- Hours: Number of hours studied.
- Marks: Marks obtained by the student.

## Libraries Used
- Pandas
- Matplotlib
- Scikit-learn

## Steps
1. Load the dataset.
2. Separate input and target variables.
3. Split the data into training and testing sets.
4. Train the Linear Regression model.
5. Predict student marks.
6. Evaluate model performance.
7. Display the results using a graph.

## Conclusion
This project demonstrates how supervised machine learning can predict student marks based on study hours.
